# The One-Line Laugh

Entry for the [make.fun bounty "The One-Line Laugh"](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f): one funny line, at most 200 characters, judged two at a time by the house judge.

## The line

> My fitness tracker says I burned 400 calories today, mostly from furiously closing pop-ups begging me to rate them.

## Run it

```sh
node main.ts
```

`main.ts` validates the line (one sentence, 1–200 characters, single line) and writes it to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set, for local validation).
